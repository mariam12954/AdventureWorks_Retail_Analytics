AdventureWorks Retail Analytics

Overview

AdventureWorks Retail Analytics is a data analysis project using SQL Server and Power BI to explore retail business performance. The project covers sales, customers, products, and geographic territories through SQL queries, exported CSV results, and interactive Power BI dashboards.

Tools & Technologies

- SQL Server
- SQL
- Power BI
- CSV
- GitHub

SQL Analysis

I used SQL to analyze the AdventureWorks database and investigate different aspects of retail business performance.

The analysis includes:

- Sales analysis
- Customer analysis
- Product analysis
- Territory and regional performance

SQL Techniques

- Joins
- Common Table Expressions (CTEs)
- Aggregate functions
- Window functions, including "RANK()", "NTILE()", and "LAG()"

More than 50 query result sets were exported to CSV files for further review and analysis.

Power BI Dashboards

The project includes a Power BI report containing six dashboard pages for exploring retail performance.

The dashboards focus on sales, customers, products, and regional performance, presenting business data through visual reports.

Repository Structure

- "data/" — Exported CSV files containing SQL query results.
- "sql/" — SQL queries used for data analysis.
- "AdventureWorks_Retail_Analytics.pbix" — Power BI report containing the dashboards.

Key Skills

- SQL querying and data analysis
- Joins, CTEs, and window functions
- Data aggregation and ranking
- CSV data export
- Power BI reporting and visualization
- Business and retail analytics
